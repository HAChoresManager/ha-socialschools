# Beveiligingsbeleid

Vind je een kwetsbaarheid in deze integratie, meld die dan **niet** via een openbaar issue.
Gebruik de privémeldingsfunctie van GitHub:
[Report a vulnerability](https://github.com/HAChoresManager/ha-socialschools/security/advisories/new)
(tabblad *Security* → *Report a vulnerability*).

Beschrijf wat je vond, hoe het te reproduceren is en welke versie je gebruikt. Stuur geen
wachtwoorden, tokens of andere persoonlijke gegevens mee. Alleen de nieuwste versie op `main`
krijgt beveiligingsupdates.

Found a vulnerability? Please report it privately through
[GitHub private vulnerability reporting](https://github.com/HAChoresManager/ha-socialschools/security/advisories/new),
not in a public issue.
